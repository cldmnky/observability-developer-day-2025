# OpenShift Deployment

This directory will contain OpenShift deployment manifests for the observability demo applications.

## Structure

- `go/` - Go API deployment manifests
- `node/` - Node.js web app deployment manifests
- `quarkus/` - Quarkus API deployment manifests

## Services

- **Go API**: Port 4001
- **Node.js Web App**: Port 4002
- **Quarkus API**: Port 4003
